- Developing tactile 3D topographic models for educational use using elevation data and 3D printing.
- Built and tested a terrain-modeling workflow using TouchTerrain and UltiMaker Cura, including STL generation, model scaling, slicing, and print-time estimation.
- Evaluating model scale, base thickness, print settings, and post-processing through prototype test prints on a Creality Ender-3 V3 KE.
